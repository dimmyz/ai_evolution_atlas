## What we are building

An interactive, source-grounded website that explains the evolution of modern foundation AI from the Transformer era to current multimodal, reasoning and agentic systems.

The first release is deliberately narrower than “all of AI history”:

- primary scope: **2017–2026**;
- 30–40 curated milestones;
- interactive timeline;
- model/technology lineage view;
- people and organizations as connected entities;
- source-backed detail cards;
- filters/search;
- polished desktop experience and usable mobile fallback;
- no backend in Sprint 1.

## What this pilot is really testing

The product matters, but the factory is also under test:

`human intent -> Strateg -> canon -> Orchestrator -> DAG -> specialists -> same-card review -> factual/visual/engineering evidence -> human acceptance`

The human should not need to run npm commands, install browsers, move routine cards, or inspect worker chat logs.
