# Factory Test Plan

Measure at closure:
- number of cards;
- first-pass approvals;
- 1/2/3-cycle reworks;
- blocked/escalated cards;
- wrong-workspace attempts caught before acceptance;
- human interventions after kickoff;
- Orchestrator wake/watch count;
- parallel-write conflicts;
- role routing mistakes;
- Sonnet Reviewer reversals / useful criticisms;
- total automated gates executed by agents rather than human;
- final factual/visual/engineering/product verdicts.

## Specific hypotheses

H1 — Strateg can compile the pack into a real Hermes board without restating product requirements in chat.

H2 — Orchestrator can supervise a research + code DAG without continuous human PM work.

H3 — Workspace provenance prevents Aquarium-style cross-project false green.

H4 — Sonnet 5 as independent judge catches defects Grok/Terra/LUNA workers miss.

H5 — Screenshot + Critic + human visual gate prevents “48 tests green, product looks bad”.

H6 — File ownership boundaries reduce merge/composition collisions.

H7 — Event/bounded duty reduces unnecessary Orchestrator polling compared with Aquarium.
