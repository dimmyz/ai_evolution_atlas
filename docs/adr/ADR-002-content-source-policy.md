# ADR-002 — Source-grounded content policy

**Status:** accepted seed policy.

## Decision

The published dataset is curated and source-grounded.

- primary sources preferred for core release/technical facts;
- Epoch AI and Stanford AI Index are allowed as discovery/cross-check/independent context sources;
- every publishable milestone carries source IDs;
- every strong directional relation carries evidence;
- low-confidence editorial inference is labeled or omitted;
- exact date precision is never invented;
- LLM-generated prose is not a source.

## Why

The website’s differentiation is not merely interaction. It is an understandable map whose relationships can be inspected and challenged.
