# Research source baseline — pre-kickoff web research

This file is a **starting map**, not the final history dataset.

## 1. Epoch AI — Data on AI Models

Use:
- discovery of candidate notable/frontier models;
- cross-checking dates, organizations and model metadata;
- broad trend/context support.

Strengths:
- actively maintained large dataset;
- transparent documentation and inclusion criteria;
- downloadable data;
- CC BY reuse with attribution.

Do not:
- treat every field as sufficient primary evidence for a narrative claim;
- import thousands of records into the MVP.

Reference: `https://epoch.ai/data/ai-models`

## 2. Stanford HAI — AI Index 2026

Use:
- independent context about model development, technical performance and ecosystem trends;
- cross-checking major shifts/claims.

Reference: `https://hai.stanford.edu/ai-index/2026-ai-index-report`

## 3. Transformer primary anchor

Google Research publication page for **Attention Is All You Need** records the 2017 Transformer paper and its core architectural claim.

Reference: `https://research.google/pubs/attention-is-all-you-need/`

## 4. Vendor/lab primary sources

For individual model/system milestones prefer official release notes, model/system cards and technical reports from the actual developer.
